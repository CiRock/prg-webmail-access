# Port Rose webmail access

Static entry point for https://posta.portrosegroup.it/.
It redirects to the official OVHcloud Italian webmail login.

This repository contains only public redirect configuration.
No credentials, mailbox contents, account inventories, or PDF documents are stored here.

GitHub Pages serves the `main` branch, root directory.
DNS: `posta.portrosegroup.it CNAME cirock.github.io`.
